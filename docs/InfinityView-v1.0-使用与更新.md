# InfinityView v1.0

LightView 从本版正式更名为 InfinityView，程序版本 1.0.0。适用于 Windows 11 x64，使用系统自带 .NET Framework 4.8 或更高版本，无需额外安装 .NET 运行时。

## 更新与便携使用

关闭现有 LightView/InfinityView 窗口后运行同批 InfinityView 安装器（本批文件名 InfinityView-1.0.0-win-x64-setup.exe）。安装器识别原安装，保留所在磁盘和上级目录，将末级 LightView 文件夹自动改名为 InfinityView；原本自定义的其他目录名保持不变。保留现有设置及整理预设，并保留升级备份。若发现程序仍在运行、目录身份不符或文件被外部修改，会停止更新；不强制结束进程。不修改 Windows 的 UserChoice 默认关联。

本批同步把默认用户数据目录从 `%LOCALAPPDATA%\LightView` 整体迁至 `%LOCALAPPDATA%\InfinityView`，包含原设置、备份和操作记录，不重置配置。目标已存在时停止，不覆盖、不自动合并。显式配置的 `INFINITYVIEW_DATA_DIR`（优先）或旧 `LIGHTVIEW_DATA_DIR` 保持原位置；便携版继续使用旁置 UserData。安装升级失败会尝试回退原程序、卸载信息和目录名，遇外部占用或冲突则保留现场与备份。

为保留旧默认关联，安装AppId、ProgId和注册键等内部兼容标识继续沿用，不必手工更名。Windows 默认应用中显示 InfinityView，WebP 是否设为默认仍由你在系统中选择。旧快捷方式仅在确认归属后退役并先留备份。本批图标使用用户提供的30°旋转逆渐变SVG，深色背景为主图标。

便携ZIP包含完整依赖，整包解压后运行 InfinityView.exe；同批也附可直接运行的完整展开目录。保留 portable 标记。便携设置放在旁置 UserData，不覆盖日常配置。更新日常安装请使用安装器，不把便携文件直接覆盖到安装目录。

## 本版变化

- 图片详情位于设置第二页；关于、恢复本页默认等入口随排序正确工作。
- 默认 A/D 分别激活左右窗格，←/→ 切图；移除 W/S 的重复出厂绑定。旧的完整出厂配置会清理这对重复项，其他自定义备用绑定保留并明确标为“备用”。
- Delete 将焦点侧有效原图直接移入 Windows 回收站，不逐次确认，不永久删除回退。长按不会连续删除。若图片已变化、仍在读取或无法回收，会停止并提示。成功后只切换原操作侧；另一侧若显示同一文件，其旧版本会变为不可整理。
- 已删除照片通过 Windows 回收站恢复；InfinityView 的 Ctrl+Z 仍用于原有复制/移动历史，不作为回收站撤销入口。旧自定义配置未设置删除命令且 Delete 未被占用时补入默认绑定；显式清空或已有绑定不覆盖。
- 支持 JPG、JPEG、PNG、BMP、WebP。WebP 随包提供 libwebp 解码库，支持有损、无损、透明、ICC 与 EXIF 方向；动画 WebP 显示合成后的首帧，不播放动画。图像仍经过原有显示色彩转换与缓存管线。
- 新 InfinityView 蓝色图标；其余图片查看、独立分屏、双侧直方图与可自定义详情等功能保留。

鼠标：当前窗格左半/右半单击切图，右键拖动，中键全屏；侧键1以光标为中心100%，侧键2适配。对比非活动侧首击只激活。Tab详情、反引号直方图、C对比、X联动、F打开、Home设置、R资源管理器定位、Ctrl+C复制拍摄信息、E收藏复制、Q废片移动。整理目标由你配置，默认留空，原字节处理、不覆盖同名文件。
